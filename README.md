# Erdős–Surányi Problem 708

Исследовательский репозиторий по проблеме Эрдёша №708.

## Постановка

Пусть A — множество из n различных целых чисел
от 2 до M, где M = max(A). Рассматриваем интервал
I из M последовательных целых чисел.

Обозначим τ(A,I) минимальное число различных
элементов I, произведение которых делится на
произведение всех элементов A.

Исследуем величину g(n), получаемую максимизацией
τ(A,I) по допустимым A и I.

Главная цель: доказать g(n) ≤ (2 + o(1))n.

## Текущий статус

Общая асимптотическая оценка остаётся открытой.

В reports/structural-research.md представлены
письменные доказательства новых утверждений:

- Оценка τ(A,I) ≤ 2n + C(k) для семейств с
  ограниченным числом общих внутренних делителей.
- Совместное покрытие при попарно взаимно
  простых внутренних делителях и ацикличности.
- Оценка через ширину семейства носителей
  простых степеней.
- Редукция для модулей из четырёх простых.

Это авторские исследовательские результаты.
Независимая рецензия и Lean-верификация
новых теорем пока отсутствуют.

## Воспроизведение

Требуется Python 3.10+.
Внешние пакеты не нужны.

```bash
python3 code/check.py
python3 code/archive_g3.py
python3 code/archive_repetitions.py
```

Проверки подтверждают вычислительные утверждения
в пределах реализованных тестов, но не заменяют
общих математических доказательств.
