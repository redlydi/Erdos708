# Erdős 708 — начальный Lean-проект

Это **дополнение** к https://github.com/redlydi/Erdos708. Оно не заменяет основной `README.md`, исследовательские отчёты или Python-код.

## Состав

- `lean-toolchain` — фиксированная версия Lean **4.8.0** (выбрана для совместимости с ранее сохранённым `Erdos708.lean`).
- `lakefile.lean` — конфигурация Lake с Mathlib v4.8.0.
- `Erdos708Formal.lean` — корневой модуль библиотеки.
- `Erdos708Formal/Support.lean` — первые законченные тексты Lean-доказательств о носителях делимости: включение, монотонность, вложенность носителей степеней и проверка локального примера 210.
- `.github/workflows/lean.yml` — GitHub Actions: `lake build` при push / PR и по ручному запуску.
- `legacy/Erdos708.lean` — **копия ранее загруженного Lean-файла**, отдельный исторический сертификат для оценки g(15) ≥ 22. Файл не включён в основную компиляцию и не подтверждён в текущем сеансе.
- `formal/STATUS.md` — точный статус математических утверждений.

## Проверка

В среде с установленным Lean/elan:

```sh
lake update
lake exe cache get
lake build
```

Для дополнительной исторической проверки:

```sh
lake env lean legacy/Erdos708.lean
```

В GitHub открыть вкладку **Actions → Lean 4 formal checks**. Для основного проекта ожидается `lake build`. Ручной запуск с `verify_legacy=true` отдельно проверяет старый файл (может выполняться долго).

**Не перепутать:** исходники для небольших лемм подготовлены, но в среде сборки этого архива не было установленного Lean. До первого зелёного запуска Actions **никакая новая лемма не помечается как фактически скомпилированная**. Тем более глобальные теоремы из отчёта §1–4 не формализованы.

## Загрузка из ZIP в GitHub

GitHub не распаковывает загруженный ZIP автоматически. Распакуйте архив на телефоне, затем добавьте его файлы **с сохранением относительных путей** в корень репозитория. Не загружайте всю папку `Erdos708-Lean-Starter` как дополнительный уровень каталога. Существующий корневой `README.md` не меняйте.

Полезные ссылки: GitHub Actions https://github.com/leanprover/lean-action ; Mathlib https://github.com/leanprover-community/mathlib4 .
