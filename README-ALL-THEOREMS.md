# Erdős–Surányi №708 — параллельная формализация

Это **дополнение** к уже работающему Lean-проекту в GitHub. Оно не заменяет `Erdos708Formal.lean`, `lakefile.lean` и существующий workflow.

## Что есть

Восемь модулей по основным направлениям из REPORT.md. В каждом только простая вспомогательная лемма о делимости. **Ни одна из основных новых теорем ещё не формализована.** Смотрите `formal/ALL-THEOREMS-STATUS.md`.

## Как использовать

1. Загрузить папку `Erdos708Formal/` и `formal/` в корень репозитория с сохранением путей.
2. Добавить `.github/workflows/lean-all.yml` **вручную через GitHub**, так как GitHub Actions bot не может создать workflow без специальных прав.
3. Actions → `Lean 708 all modules` → `Run workflow`.
4. Добавлять настоящие формулировки и доказательства в каждый модуль, сохраняя строгий статус.

В workflow используется уже работающая версия Lean и Mathlib из существующего проекта. Файл `lake-manifest.json` создаётся `lake update`.
